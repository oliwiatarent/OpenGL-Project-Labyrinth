#### Opis projektu
Projekt demonstracyjny aplikacji graficznej napisanej w języku C++ z wykorzystaniem biblioteki OpenGL. Aplikacja umożliwia poruszanie się kamerą, renderowanie prostych figur geometrycznych oraz bardziej złożonych modeli 3D, obsługę shaderów, a także renderowanie oświetlenia.

#### Technologie
- C++
- OpenGL
- GLFW
- GLM
